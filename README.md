# Tipp-Trainer Deutsch

Ein leichtgewichtiger Tipp-Trainer für die deutsche Sprache (QWERTZ-Layout).
Läuft vollständig im Browser – keine Installation, keine Abhängigkeiten, keine Server.

## Dateien
- **`index.html`** – Struktur und Layout
- **`style.css`** – dunkles Theme, Tastatur- und Statistik-Optik
- **`app.js`** – Wortschatz, Tastaturlogik, Statistiken und Rekorde

## Starten
Doppelklicke auf `index.html` und öffne sie in deinem Browser.
(Oder starte einen beliebigen statischen Server in diesem Ordner.)

## Modi
| Modus | Inhalt |
|-------|--------|
| Anfänger | Grammatikalisch korrekte Phrasen: Artikel + Nomen (der Tag, die Zeit, das Auto) |
| Fortgeschritten | Grammatikalisch korrekte Phrasen: Adjektiv + Nomen (wichtige Frage, schneller Zug) |
| Sätze | Komplette, alltägliche Sätze |
| logo! | 137 Sätze aus der aktuellen logo!-Sendung (transkribiert) |
| logo! | 137 Sätze aus der aktuellen logo!-Sendung (transkribiert) |

## Bedienung
- Tippe einfach mit – die Tastatur-Anzeige hebt die nächste nötige Taste hervor.
- **`Esc`** bricht die Runde ab · **`⏎`** / **`Leertaste`** startet nach dem Ende neu.
- Falsche Tasten zählen als Fehler, der Text wird aber weitergegeben – so bleibst du im Fluss.

## Statistiken
- **WPM** – Wörter pro Minute (zählt korrekte Tasten / 5 pro Minute)
- **Genauigkeit** – korrekte Tasten in Prozent
- **Fehler** und **Zeit** als Übersicht
- Pro Modus wird dein **persönlicher Rekord** im Browser gespeichert (localStorage).

> Hinweis: Das Tastatur-Layout ist deutsch/QWERTZ und berücksichtigt Sonderzeichen wie ä, ö, ü und ß.
